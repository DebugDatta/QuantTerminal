# Regime Detection & Monte Carlo Simulation

All models operate on return sequences derived from OHLCV data.

---

## Regime Detection

Three methods to identify distinct market regimes from return patterns.

### 1. Hidden Markov Model (HMM)

**Library:** `hmmlearn`

Models the return distribution as being generated by a hidden state (regime) that transitions according to a Markov process.

**Model:**
```
P(r_t | S_t = i) ~ N(μ_i, σ_i)
P(S_t = j | S_{t-1} = i) = A_{ij}
```

**Parameters:**
| Parameter | Default | Range |
|---|---|---|
| n_components | 3 | 2–6 |
| covariance_type | full | full, diag, spherical, tied |
| n_iter | 1000 | 100–10000 |
| random_state | 42 | Any int |

**Output:**
| Field | Description |
|---|---|
| State Probabilities | P(regime) for each date (n × k matrix) |
| Most Likely States | The regime with highest probability per date |
| Transition Matrix | k × k probability matrix of regime switches |
| Means | Mean return per regime |
| Covariances | Volatility per regime |
| Steady-State Probabilities | Long-run probability of each regime |

### 2. Gaussian Mixture Model (GMM)

**Library:** `sklearn.mixture`

Models the unconditional return distribution as a mixture of Gaussian components (regimes) without temporal structure.

**Parameters:**
| Parameter | Default | Range |
|---|---|---|
| n_components | 3 | 2–6 |
| covariance_type | full | full, diag, spherical, tied |
| random_state | 42 | Any int |

**Output:**
| Field | Description |
|---|---|
| Labels | Most likely regime for each observation |
| Probabilities | P(regime) for each observation |
| Means | Mean return per regime |
| Covariances | Volatility per regime |
| Weights | Mixing proportion of each regime |

### 3. Change Point Detection (CPD)

**Library:** `ruptures`

Detects points where the statistical properties of the return series change abruptly.

#### CUSUM (Cumulative Sum)

Standardizes returns before applying the cumulative sum, ensuring the threshold is scale-invariant.
```
g(t) = |cumsum((r_t - μ) / σ)| / sqrt(n)
```
Flags a change point when the standardized cumulative deviation exceeds a threshold. The `/ sqrt(n)` term normalizes by the number of observations.

**Parameters:**
| Parameter | Default | Range |
|---|---|---|
| threshold | 1.0 | 0.5–5.0 |

#### PELT (Pruned Exact Linear Time)
```
min Σ cost(y_{ti:ti+1}) + penalty
```
Penalized likelihood method that finds the optimal number and location of change points.

**Parameters:**
| Parameter | Default | Range |
|---|---|---|
| penalty | 10 | 1–100 (higher = fewer change points) |
| model | rbf | rbf, linear, ar, normal |

**Output:**
| Field | Description |
|---|---|
| Change Point Indices | Array of dates where regimes change |
| N Regimes | Number of detected regimes = n_changepoints + 1 |
| Segment Statistics | Mean and volatility per detected segment |

### Visual Outputs
- **Regime Timeline** — price chart with colored background bands per regime
- **State Probabilities** — stacked area chart showing probability over time (HMM)
- **Return Distribution by Regime** — overlaid histograms per regime

## Monte Carlo Simulation

All simulation methods estimate parameters from historical returns and generate random paths.

### 1. Geometric Brownian Motion (GBM)

**Model:**
```
dS = μ * S * dt + σ * S * dW
S_{t+1} = S_t * exp((μ - σ²/2) * dt + σ * ε * sqrt(dt)),  ε ~ N(0,1)
```

**Parameters:**
| Parameter | Default | Range |
|---|---|---|
| n_simulations | 1000 | 100–10000 |
| n_days | 252 | 21–756 |
| mu_method | historical | historical, drift |
| sigma_method | historical | historical, ewma |
| dt | 1/252 | Daily timestep |

**Output:**
| Field | Description |
|---|---|
| Paths | `n_simulations × n_days` matrix of simulated prices |
| Percentiles | 5th, 25th, 50th, 75th, 95th percentiles at each step |
| Terminal Distribution | Histogram of final prices |

### 2. Bootstrap Simulation

Randomly samples blocks of historical returns to generate new paths.

**Parameters:**
| Parameter | Default | Range |
|---|---|---|
| n_simulations | 1000 | 100–10000 |
| n_days | 252 | 21–756 |
| block_size | 5 | 1–63 (size of resampled blocks) |
| replace | True | Sample with replacement |

**Output:** Same as GBM.

### 3. Portfolio Simulation

Simulates correlated multi-asset paths using Cholesky decomposition of the covariance matrix.

**Parameters:**
| Parameter | Default | Range |
|---|---|---|
| weights | equal | Array of asset weights |
| n_simulations | 1000 | 100–10000 |
| n_days | 252 | 21–756 |

**Output:**
| Field | Description |
|---|---|
| Paths | `n_simulations × n_days` matrix of portfolio values |
| Terminal Statistics | Mean, median, percentiles, VaR of final portfolio value |

### Simulation Statistics Table
| Statistic | Description |
|---|---|
| Mean Final Price | Average of all simulated final prices |
| Median Final Price | 50th percentile |
| 5th Percentile | Worst-case (95% confidence lower bound) |
| 95th Percentile | Best-case (95% confidence upper bound) |
| VaR (95%) | Portfolio VaR at 95% confidence |
| Probability of Loss | % of paths ending below starting value |

### Visual Outputs
- **Fan Chart** — all simulated paths with percentile shading (transparent bands)
- **Terminal Distribution** — histogram of final prices with percentiles marked
- **Selected Percentiles** — 5th/25th/50th/75th/95th percentiles over time
